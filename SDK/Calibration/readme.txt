Press G to start the wizard. Follow the big magenta prompts on screen — it advances automatically, no keys needed:

HOLD STILL (3 s) — measures gyro bias, gravity, and which axis is up. Keep the device resting still.
PUSH UP — one clear push upward, then stop.
PUSH DOWN
PUSH LEFT
PUSH RIGHT
PUSH FORWARD (away)
PUSH BACK (toward you)

Each step shows a 2-second GET READY: PUSH … countdown, then a 3-second capture window. When it finishes, it flashes CALIBRATED OK and prints GUIDED CALIBRATION done. All 6 directions mapped. in the terminal. Now up moves the hand up, right moves it right, forward moves it forward — regardless of how the chip is mounted.

You still have C for the quick still-only calibration (up/down only, gravity-based) and R to re-center. The panel shows R = zero C = calibrate G = guided.
